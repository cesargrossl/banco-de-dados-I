# 🗄️ Modelagem Conceitual

Está pasta contém conteudos abordando o **Modelo Conceitual**.

## 🛠️ Ferramentas utilizadas

### 🔷 Draw.io / diagrams.net

O **Draw.io (diagrams.net)** é uma ferramenta gratuita para criação de diversos tipos de diagramas, incluindo diagramas utilizados na modelagem de banco de dados.

Pode ser utilizado para:

- Modelo Entidade-Relacionamento (MER)
- Diagrama Entidade-Relacionamento (DER)
- Notação de Peter Chen
- Modelo Lógico
- Representação de tabelas
- Relacionamentos `1:1`, `1:N` e `N:N`
- Chaves Primárias (PK)
- Chaves Estrangeiras (FK)

**Acessar:**  
https://app.diagrams.net/

O Draw.io é gratuito e pode ser utilizado diretamente pelo navegador, sem necessidade de criar uma conta. Também possui versão desktop.

---

### 🟣 ERDPlus

O **ERDPlus** é uma ferramenta online voltada especificamente para **modelagem de banco de dados**.

Pode ser utilizado para:

- Modelo Entidade-Relacionamento
- Notação de Peter Chen
- Entidades e atributos
- Entidades fracas
- Relacionamentos e cardinalidades
- Modelo Relacional
- Conversão de DER para Modelo Relacional
- Geração de SQL
- Star Schema

**Acessar:**  
https://erdplus.com/

Uma das principais vantagens do ERDPlus é permitir transformar automaticamente um **Diagrama ER em um Modelo Relacional**, além de possibilitar a geração de comandos SQL.
